# Требования проекта GophKeeper

## Функциональные требования

### Сервер
- Регистрация пользователей.
- Аутентификация пользователей.
- Авторизация доступа к приватным данным.
- Хранение приватных данных (логин/пароль, текст, бинарные, банковские карты).
- Синхронизация данных между несколькими авторизованными клиентами одного владельца.
- Передача приватных данных владельцу по запросу.

### Клиент
- Аутентификация и авторизация пользователя на сервере.
- Доступ к приватным данным по запросу.

### Данные
- Поддержка типов: логин/пароль, текст, бинарные, банковские карты.
- Поддержка произвольной текстовой метаинформации для любых данных.

## Нефункциональные требования
- Клиент распространяется как CLI‑приложение для Windows, Linux, MacOS.
- Клиент показывает версию и дату сборки бинарного файла.
- Безопасная передача данных между клиентом и сервером.
- Безопасное хранение данных.
- Покрытие кода юнит‑тестами не менее 70%.
- Экспортируемые функции/типы/переменные/пакеты документированы.

## Необязательные функции
- Поддержка OTP.
- TUI интерфейс.
- Бинарный протокол.
- Функциональные/интеграционные тесты.
- Swagger/OpenAPI описание протокола.
